Introduction

Welcome to the SAM Particle Counter manual.

This document is a draft for an online manual that explains the analysis workflow in detail, from image loading to final export of particle counts and tables. It is written in English so it can be used as the source for a later Japanese version.

What this application does

SAM Particle Counter is a napari-based desktop tool that helps you:

  • draw a rectangular region of interest (ROI),
  • run SAM2-based automatic segmentation,
  • optionally refine segmentation with point prompts and manual label edits,
  • export overlays, CSV tables, and run metadata.

The typical usage pattern is:

  1. Load image
  2. Draw ROI
  3. Crop to ROI
  4. Run SAM2 auto segmentation
  5. Review/edit labels
  6. Export artifacts

Before You Start

Environment setup

Please complete project setup first (see the main README for full commands).

At a minimum:

  • Python and dependencies installed via uv
  • SAM2 setup script executed for your OS
  • App starts successfully with:
uv run main.py

Recommended input image conditions

For stable segmentation quality:

  • Use images with clear contrast between particles and background.
  • Avoid severe blur or compression artifacts when possible.
  • If images are very large, use ROI cropping to reduce computation and memory load.

Detailed Analysis Procedure

Step 1. Load an image

Open your image in napari (drag-and-drop or File > Open...).

When the first image layer is added, the app automatically creates a corresponding ROI layer named:

  • <image_name>_ROI

Why this matters

All downstream operations are tied to layer names. Keeping the base image name unchanged helps the tool resolve related layers automatically.

Step 2. Draw ROI on the *_ROI layer

  1. Select the ROI layer (<image_name>_ROI).
  2. Draw a rectangle using the Shapes tool.
  3. If multiple rectangles exist, the most recently drawn ROI is used.

Practical tips

  • Include all target particles with a small safety margin.
  • Exclude unrelated structures as much as possible.
  • If segmentation is slow, start with a smaller ROI and expand later.

Step 3. Run Crop to ROI

Press the right-dock button:

  • Crop to ROI

This creates a cropped image layer:

  • <image_name>_cropped

and stores crop metadata internally (source image/layer names and crop coordinates).

What to check

  • The cropped layer appears in the layer list.
  • The cropped region visually matches your intended analysis area.

If no valid rectangle exists, cropping will not run.

Step 4. Run SAM2 auto segmentation

Select <image_name>_cropped, then execute:

  • Run SAM2 auto segmentation

Main parameters (first-pass recommendation)

  • points_per_side: start around 56 (higher = denser proposals, slower)
  • pred_iou_thresh: start around 0.84
  • stability_score_thresh: start around 0.90
  • crop_n_layers: start with 1
  • crop_n_points_downscale_factor: start with 1
  • deduplicate_masks: usually ON
  • contain_thresh: start around 0.90
  • iou_thresh: start around 0.70
  • output_mode: usually labels (or both if polygon output is also needed)

Output layers

Depending on output_mode, the app creates:

  • <image_name>_cropped_sam2_auto (shape polygons)
  • <image_name>_cropped_sam2_auto_labels (editable labels)
  • <image_name>_cropped_sam2_auto_labels_original (non-editable reference copy)
  • ID text overlay layer for label numbers

Interpretation notes

  • With deduplication enabled, overlapping/redundant masks are reduced.
  • Label IDs are integer objects (1..N), with 0 as background.

Step 5. Optional refinement (recommended for publication-quality counts)

You can refine the result in two ways.

A) Point-prompt refinement with SAM2

  1. Use Create prompt points layer
  2. Choose foreground/background target
  3. Add points on the cropped image
  4. Run Run SAM2 point prompt

This produces prompt-based polygon candidates (*_sam2_points) that can guide manual correction.

B) Direct manual label editing

Use napari label editing tools on:

  • <image_name>_cropped_sam2_auto_labels

Typical edits:

  • split merged particles,
  • remove obvious false positives,
  • add missing particles.

Recommendation: Keep edits minimal and traceable, and document any manual criteria in your experiment notes.

Step 6. Export results

Execute:

  • Export segmentation artifacts

Choose an output directory (default: ./outputs).

A timestamped export folder is generated, such as:

  • example_01_20260421T094932Z

Exported files

Typical files include:

  • source_with_roi.png (original image + ROI box)
  • cropped_image.png (cropped analysis region)
  • sam2_only_overlay.png (overlay from SAM2 auto result)
  • final_overlay.png (overlay from final selected labels)
  • sam2_blobs.csv (per-particle table from SAM2)
  • final_blobs.csv (per-particle table from final labels)
  • run_metadata.json (parameters, counts, environment, output list)

Count definitions

The export metadata reports:

  • sam2_raw_count_before_dedup
  • sam2_after_dedup_count
  • dedup_removed_count
  • final_count
  • manual_delta_count_net

This helps separate model output from manual adjustments.

Suggested QA Checklist

Before accepting final counts:

  • ROI includes all relevant particles and excludes irrelevant regions.
  • SAM2 masks align with object boundaries at representative locations.
  • Major merge/split errors are corrected.
  • Final overlay and CSV rows are consistent.
  • Run metadata is archived together with exported images.

Troubleshooting

No cropped layer is created

  • Confirm the active layer is *_ROI.
  • Confirm at least one valid rectangle exists.

SAM2 auto segmentation fails

  • Re-check SAM2 setup scripts and model files.
  • Try a smaller ROI.
  • Reduce proposal density (points_per_side).

Export fails

  • Ensure a cropped layer exists.
  • Ensure SAM2 label layer exists.
  • Check write permission for the output directory.

Notes for Future Japanese Translation

When creating the Japanese edition, consider keeping:

  • button names in English (exact UI labels),
  • terminology mappings in a glossary (ROI, mask, label, deduplication),
  • one-to-one heading structure with this English version for maintainability.

# Troubleshooting

## No cropped layer is created

- Confirm the active layer is `*_ROI`.
- Confirm at least one valid rectangle exists.

## SAM2 auto segmentation fails

- Re-check SAM2 setup scripts and model files.
- Try a smaller ROI.
- Reduce proposal density (`points_per_side`).

## Export fails

- Ensure a cropped layer exists.
- Ensure SAM2 label layer exists.
- Check write permission for the output directory.
